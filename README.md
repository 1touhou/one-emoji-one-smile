Entry for make.fun's "One Emoji, One Smile" bounty: the program writes exactly one emoji — **🤗**, the hugging face — to `/output/entry.txt`, nothing else. It was revised from a first draft of 😊: the plain smiling face is the default warm smile, the first emoji most people reach for, so it reads as unchosen and likely duplicates a crowd of identical entries. 🤗 keeps the warm smile and adds open arms — an offered hug, the warmest gesture a stranger can make, instantly readable by any age or background, welcoming without intimacy, sarcasm or flirtation.

## Run it

```sh
node main.ts
```
